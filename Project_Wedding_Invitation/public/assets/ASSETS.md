# Asset sources

This fan-made academic project uses four different published promotional stills from *My Demon*. The images are loaded from the source host instead of redistributed as downloaded copies, so the page needs an internet connection to display them. Image copyrights remain with their respective owners and publishers.

1. **Photo 1 — beach / wrist contract scene:** [Soompi, “Kim Yoo Jung Falls For Song Kang And Makes A Dangerous Deal In My Demon”](https://www.soompi.com/article/1621955wpp/kim-yoo-jung)

2. **Photo 2 — close-up romantic still:** [Soompi, same promotional-stills article](https://www.soompi.com/article/1621955wpp/kim-yoo-jung)
   Direct image: https://0.soompi.io/wp-content/uploads/2023/10/24202600/My-Demon02.jpeg

4. **Photo 4 — green-suit scene:** [Soompi, same promotional-stills article](https://www.soompi.com/article/1621955wpp/kim-yoo-jung)

The photo classes `.photo-1` through `.photo-4` each use a different image URL; the same source photo is reused only where the scrapbook layout intentionally repeats a matching polaroid/thumbnail. No AI-generated couple image is used.
